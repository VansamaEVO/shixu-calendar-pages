## 为什么打开方式更轻

页面由HTML、CSS和原生JavaScript组成，不安装Python、React、图表库或外部字体，也不等待Streamlit服务启动、唤醒及WebSocket连接。未配置设备时不发任何云端请求，直接显示完整界面。

配置后，设备属性与网关状态并行读取，每5秒刷新，读取不重叠，后台标签页暂停轮询。历史温湿度曲线由用户点按钮后读取，不占用首次加载。酒精曲线只记录本次浏览收到的真实有效采样，最多120点、一小时内；跨较长缺报或观察到的离线处断线。没有任何模拟数据或浏览器自行走动的“设备时钟”。

这优化的是页面加载路径，不承诺固定秒开；GitHub Pages可达性、浏览器缓存和到OneNET的网络仍会影响实际体验。界面加载快不代表云端电机命令瞬间执行。

参考：[GitHub Pages静态托管](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)、[Streamlit应用休眠](https://docs.streamlit.io/deploy/streamlit-community-cloud/manage-your-app#app-hibernation)。

## 连接配置与密钥边界

点右上角“连接设备”，填写与原在线版同设备的以下配置：

- 产品ID：原 `ONENET_PRODUCT_ID`。
- 设备名称：原 `ONENET_DEVICE_NAME`。
- 设备级HTTP API Token：原 `ONENET_TOKEN`，不要填用户级AccessKey、Wi-Fi密码或任意未经核实的MQTT专用Token。

网页只向固定的 `https://iot-api.heclouds.com` 发送请求，Token只放在授权请求头、保存在当前页面内存，不写入URL、日志、localStorage、sessionStorage、源码或GitHub。浏览器表单自动填充不由网页控制，请不要让浏览器保存Token。关闭、刷新或断开页面后需重新填写Token。产品ID和设备名称可在当前浏览器记住，控制待核对标记只保存时间和是否涉及电机，不保存密钥、命令参数或返回原文。

与原Streamlit公开演示版不同，**新浏览器不会自动获得设备授权**，老师仅打开网址能看界面，填写设备级Token后才能看实时值、控制设备。不要为省事把Token写入公开HTML/JS或放进分享链接。如果要做到“老师打开就能用、且不接触Token”，需另加安全后台转发，纯GitHub Pages自身不能保管服务器密钥；原Streamlit版仍可用于免填写演示。

OneNET必须允许浏览器跨域访问这些接口。本轮对属性、网关状态、历史与控制端点发送了不含密钥和设备标识的OPTIONS预检，均返回HTTP 200、允许来源 `*` 和Authorization请求头；这不等同于已经完成真实设备授权及调速实测。此版不会关闭浏览器安全检查，不会把Token发送到第三方公共CORS代理。若有跨域/网络错误，按页面提示检查浏览器网络记录，或继续用旧Streamlit版。

## 已保留的功能

- 设备日期、时间、星期、月历；断线只显示明确标注的历史时钟，传感器当前值隐藏。
- 温度小数、湿度整数、温湿度独立阈值及分项报警来源，20秒过期、超前5秒保护。
- 日期时间写入、同步北京时间、温湿度上下限、临时消音约10秒与恢复声音。
- MQ-3的12位ADC原值、参考电压换算、相对响应指数、真实采样趋势；不虚标ppm或实际酒精浓度。
- 电机0/1/2/3档对应0%/40%/50%/60%，只展示新鲜且同批匹配的实际档位、PWM回报，不将PWM称作实测转速。
- 本次浏览操作记录；设置草稿不被常规轮询覆盖，支持手动重新载入。

同步北京时间使用访问者电脑/手机的系统时间转换为UTC+8，与旧版使用服务器时间不同。演示前确认系统时钟准确；时间明显错误也会影响上报新鲜度校验。

## 控制安全与超时

每次控制先重新读取在线状态与有效回报，参数校验通过后只POST一次。平台回复与51新的实际回报都匹配后才提示成功，旧缓存、只变动的目标档位、仅有request_id均不算成功。

整次等待最长25秒，单次读取6.5秒、POST12秒；限制等待不等于撤销硬件执行。超时、断网、主动结束等待，均不自动重发。发送前先保存非敏感待核对标记，未确认操作会阻止继续争用控制；点“刷新核对”，查看实际状态后手动解除提示。刷新、关闭后重开、重新连接也不会补发旧命令。若浏览器不能保存会话待核对标记，本次控制会在发送之前拒绝。

**网络停止不是急停，断网不自动停机。** 等待中如需立即处理，请使用板上硬件操作：进入51电机页面后K2停止，或直接断开电机/整机电源；K2不是所有页面通用的急停键。不要同时用按键、蓝牙与云端争用调速。供电扰动、LCD发白和51偶发复位属于已有硬件稳定性问题，本网页不宣称解决。
